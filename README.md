# XDeveloper Website

ساختار پروژه:
- index.html — صفحه اصلی
- store/index.html — فروشگاه با مسیر /store
- assets/style.css — طراحی شیشه‌ای، مشکی، سبز و طلایی
- assets/app.js — فیلتر فروشگاه

## اجرا
فایل‌ها را روی هاست دامنه XDeveloper.ir قرار دهید و index.html را در ریشه قرار دهید.
برای آدرس `/store`، پوشه `store` را در ریشه نگه دارید.

## توسعه آینده
ساختار کاملاً استاتیک و ماژولار است و می‌توان در آینده API، پنل مدیریت، درگاه پرداخت، دیتابیس و احراز هویت را به آن اضافه کرد.

توجه: فروشگاه فقط باید برای محصولات و خدمات قانونی و مجاز استفاده شود. ابزارهای جعل، فریب، ارسال مزاحم یا دور زدن سامانه‌های احراز هویت در نسخه پایه ارائه نمی‌شوند.
